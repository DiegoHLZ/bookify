# Bookify

Bookify is a multi-tenant SaaS and marketplace for discovering nearby bookable businesses and completing reliable reservations.

It targets multiple categories—such as beauty, health, sports, coworking and hospitality—through a shared booking kernel. AI-assisted semantic discovery is planned through provider-neutral adapters compatible with NVIDIA retrieval technology; booking correctness never depends on AI availability.

## Technology baseline

- Angular
- Spring Boot / Java 17
- PostgreSQL with recommended PostGIS support
- Spring Security and JWT
